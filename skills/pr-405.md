## Findings

### P2 — Audit malformed path validation through the governed boundary

[src/sre_agent/gateway/skills.py:164–165](https://github.com/creep1ng/sre-agent/blob/6d94a92cdbc92f85ceb265df0bc2b5b2d553d12f/src/sre_agent/gateway/skills.py#L164-L165)

FastAPI Path(pattern=...) rejects /v1/skills/INVALID/1.0.0/resolve before the handler. With a supplied valid X-Request-ID the result is 422 without request_id, and a real PostgreSQL query finds zero matching audit events. Move validation into the audited service path or handle route validation errors through it. Existing finding remains valid.

### P2 — Make the declared success model match every runtime success

[src/sre_agent/gateway/skills.py:25–28](https://github.com/creep1ng/sre-agent/blob/6d94a92cdbc92f85ceb265df0bc2b5b2d553d12f/src/sre_agent/gateway/skills.py#L25-L28)

SkillResolutionResponse forbids extras and declares only skill, whereas _finish returns skill, request_id, retryable in a JSONResponse, bypassing FastAPI model validation. A real 200 response fails SkillResolutionResponse.model_validate_json. Declare the correlation/retry fields in the response contract and validate observed response bytes against it. Existing finding remains valid.

### P2 — Return the Bearer authentication challenge on 401

[src/sre_agent/gateway/skills.py:131–134](https://github.com/creep1ng/sre-agent/blob/6d94a92cdbc92f85ceb265df0bc2b5b2d553d12f/src/sre_agent/gateway/skills.py#L131-L134)

An unauthenticated resolution returns 401 without WWW-Authenticate. The shared authentication failure handler explicitly supplies WWW-Authenticate: Bearer; this new hand-written JSONResponse omits it. The exact-head request reproduced the missing header. Preserve the shared challenge semantics on every authentication-failure route. Existing finding remains valid.
