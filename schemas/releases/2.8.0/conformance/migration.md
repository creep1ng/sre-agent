# 2.8.0 additive publication

Release 2.8.0 is additive over immutable 2.7.0. It publishes bounded administrator-only `GET /v1/usage/requests` in both canonical control-plane and standalone usage-read OpenAPI contracts, with closed response schemas for available, partial, unavailable, and legacy historical attribution. The response preserves requested assignment separately from provider-verified credited model/provider, and explicitly marks incident/run navigation unsupported. Older invocations missing snapshots are `legacy`; pre-provider rejections without assignment snapshots are `unavailable`. Neither status is inferred from the current alias. It reuses the 2.8.0 consumption schema and its own versioned error envelope; no 2.7.0 schema is a runtime dependency. Existing consumption behavior and all prior release artifacts remain unchanged.
