07 / Implementation

Use the system

Import the complete CSS entry point, build with semantic tokens, and compose domain patterns from the core classes. Framework adapters can wrap these contracts later without redefining the visual language.

Import one entry point

Load styles/design-system.css before product-specific layout styles.

Use semantic intent

Choose --ma-color-text-primary, never a primitive such as Space Indigo.

Compose domain patterns

Combine cards, badges, alerts, and timelines instead of adding one-off components.

Architecture boundary

This release is framework-agnostic because the solution design leaves the frontend framework open. A React, Vue, or mobile adapter should consume the same token and behavior contracts.
