# Governed Grafana MCP access (#187)

## Objective
Expose exactly two demo Grafana MCP tools through a governed gateway resource boundary.

## Problem and why
The existing catalog describes generic `mcp_server` and `mcp_tool` resources, while the isolated Grafana MCP integration exposes a broader upstream surface. Neither establishes MCP ownership, direct-grant discovery/invocation, or no-upstream-call denial.

## Scope and constraints
- Authorized: local contract, owner registry/lifecycle, catalog projection, gateway discovery/invocation, tests, and isolated demo evidence.
- Not authorized: unrelated LLM/Skill/BoK changes, enabling RDD, remote mutation, or exposing upstream credentials to callers.
- Upstream reference: local `origin/feat/ht-demo-mcp@84dfcb1`; the current worktree remains based on `main@137b101` until its dependency is integrated.
- Demo tools: `query_prometheus` and `query_elasticsearch`; all other upstream tools stay undiscoverable and uninvokable through this feature.
- TDD: strict, from active AGENTS.md instructions. Runner: `scripts/worktree-compose --profile checks run --build --rm python-checks pytest -q`.
- Prefer cohesive work units; ~400 authored changed lines per task is advisory, not a reason to omit tests or compress code.

## Acceptance criteria
- CA1: A versioned contract fixes the two tools, input/result shape, actions/resources, errors, timeout, and non-enumeration behavior.
- CA2: Owner-issued server/tool identity and lifecycle are authoritative; catalog is only a projection and tool→server is enforced.
- CA3: Authentication and exact direct grants precede discovery/invocation; denied requests make zero upstream calls, allowed invocation exactly one.
- CA4: Invalid input, upstream timeout/failure, and metadata-only audit are deterministic and tested.
- CA5: The final integrated candidate demonstrates the governed path on an isolated stack with sanitized evidence, proving denied calls produce zero real upstream calls and an allowed invocation produces exactly one, without treating upstream's ten tools as authorized.
